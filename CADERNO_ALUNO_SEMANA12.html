06

modelo_carregadoGauge: 1 indica que o artefato está carregado.

ETAPA 09 / 12 · 8 MINUTOS

Aprender PromQL

PromQL é a linguagem de consultas das séries coletadas pelo Prometheus.

09

Leia as quatro consultas abaixo. Você poderá executá-las no Prometheus caso siga a extensão com Docker. Mesmo sem Docker, faça a interpretação e relacione com /metrics.

PowerShell · VS Code 
sum(rate(predicoes_total[1m]))

100 * sum(rate(predicoes_total{resultado="erro"}[1m])) / clamp_min(sum(rate(predicoes_total[1m])), 0.000001)

histogram_quantile(0.95, sum by (le) (rate(latencia_inferencia_segundos_bucket[1m])))

up{job="api-observavel"}

Leitura: rate() transforma contagem em taxa/segundo; sum() agrega séries; sum by (le) preserva os limites dos buckets para estimar p95; up indica se a coleta do alvo funciona.

O Prometheus precisa de pelo menos duas amostras de scrape dentro da janela para calcular rate. Aguarde 15–30 s após inicializar a stack. Se a amostra estiver vazia ou o serviço parado, a query pode não mostrar linha.

ETAPA 11 / 12 · 8 MINUTOS

Alertas: condição e investigação

Um alerta é um sinal operacional e não uma correção automática da causa.

11
Se estiver sem Docker

Mantenha a API local rodando, gere outro incidente e rode:

PowerShell · VS Code 
python 03_gerar_trafego.py --cenario incidente --total 60
python 04_verificar_alerta.py

O script usa p95 real de requisições recentes; quando existem pelo menos 10 amostras e p95 maior que 200 ms, imprime ALERTA LOCAL. Esse teste é imediato e demonstrativo; não possui a persistência por 30 segundos que configuramos na regra do Prometheus.

Se estiver com Docker

No terminal, gere tráfego com o servidor containerizado. Acesse Prometheus /alerts e acompanhe o estado inactive → pending → firing da regra LatenciaP95Elevada. Ela exige p95 acima de 0,2 segundo por 30 segundos. Repita o tráfego se necessário e aguarde coletas suficientes.

Importante: o Prometheus mostra o alerta, mas não está configurado aqui para mandar e-mail/Slack. Para isso seria preciso Alertmanager ou Grafana Alerting. Em produção, um alerta exige equipe responsável e procedimento de resposta.
